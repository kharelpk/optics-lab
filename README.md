# Optics Lab

A physically simulated optics lab that runs in the browser: **https://kharelpk.github.io/optics-lab/**

Move, tilt or knock the optics on the bench. A robot puts them back and aligns the beam with a
policy trained by reinforcement learning (recurrent PPO; its only input is the power-meter reading).

This repository holds the built site only. The source is not included. All rights reserved.
